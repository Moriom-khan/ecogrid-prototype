# EcoGrid Energy Prototype

EcoGrid Energy Prototype is an event-driven architecture demonstration showcasing Domain-Driven Design (DDD) bounded contexts, loose coupling, observability, fault tolerance, and idempotency in a peer-to-peer renewable energy trading network.

---



---

## Installation


Install requirements using `pip`:
```bash
pip install -r requirements.txt
```

---

## Running the Prototype

To run the full end-to-end prototype simulation:
```bash
python -m app.main
```

---

## Running Tests

Execute the automated test suite and architectural fitness functions:
```bash
pytest
```
